# Firefly 双臂 IK 与电机仿真测试

小幅单臂和双臂指令均到位。扩大运动范围后，测到了两夹爪互撞、同一条手臂的连杆自碰、关节临时及持续超额定力矩、限位附近漏解和奇异位姿附近的关节解变化放大。控制器返回 `reached` 的两个往返用例也发生了自碰。

测试运行于 RTX 4090，使用 cuRobo 0.9.0、MuJoCo 3.3.7 和 PyTorch 2.9.1+cu128。动力学部分覆盖 10 个场景，每个 2 ms 物理步采样一次，共 9,850 步、19.70 秒仿真时间。

## 双臂运动、碰撞与力矩

下表的时长为指定关节**连续**高于其额定力矩的最长时段。判定接触使用 MuJoCo 已启用的碰撞几何，穿入阈值为 1 μm。力矩取每步 `qfrc_actuator` 的对应自由度，含模型配置的重力补偿和关节总输出限幅。[MuJoCo 关节重力补偿说明](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-joint-actuatorgravcomp)

| 场景 | 运动与接触 | 力矩或跟踪实测 |
| --- | --- | --- |
| 左臂或右臂单独移动 18 mm X、8 mm Z | 两个用例均到位，另一臂的指令和 TCP 均无可测变化 | 均无接触、超额定或超速 |
| 两臂同时向不同方向小幅移动 | 均到位，最大位置误差 0.125 mm | 无接触，最高为右 J3 的 8.73 N·m，额定 9 N·m |
| 两肩向外转 1.2 rad，其余参考关节固定 | 到位，全程无接触 | 左 J2 达 13.00 N·m，超额定 164 ms。右 J2 达 12.30 N·m，超额定 144 ms |
| 多关节快速外移 | 到位，两侧均有 `link_3` 与 `link_5` 自碰 | 左 J2 达 26.94 N·m，超额定 806 ms |
| 同一动作返回 home | 到位，出现自碰 | 左 J2 达到 30 N·m 峰值限幅，累计 34 ms。右 J5 达到 7 N·m 峰值限幅，累计 42 ms |
| 两肩同时向内转 0.38 rad | 第 0.120 秒双臂夹爪首次接触，最大穿入 2.82 mm，8 秒跟踪超时 | 未超额定；超力矩监测无法替代碰撞检测 |
| 两个夹爪同时闭合、张开 | 4 根手指均到位，无接触 | 未超额定；J7 实测速度最高约 1.51 rad/s，略高于模型 1.5 rad/s 的指令斜率 |
| 双臂伸展空载保持 1.5 s | 保持到位，无接触 | 左 / 右 J2 达 13.65 / 13.28 N·m，整个 1.5 s 均超额定 |
| 相同姿态，每侧 TCP 施加 1.5 kg 等效向下力 | 无接触，1.5 s 后左 / 右 TCP 偏离起始目标 103.8 / 103.1 mm | 左 / 右 J2 达 29.94 / 29.44 N·m，整个 1.5 s 均超额定 |

加载对照在 TCP 施加重力及其关于腕部质心的力矩，保持相同的初始关节角和位置指令。该试验量化当前伺服在伸展姿态下受力后的偏移。运动载荷惯量、电机温升、扭矩随转速变化以及实机夹爪传动损耗不在这一模型内。全部样本中，关节实际输出都在所设峰值限幅内；限幅时的输出无法说明未限幅需求有多大。

全范围几何测试另取 256 个双臂联合关节构型。205 个构型在当前碰撞模型中发生穿入，其中 164 个有自碰、140 个接触环境、6 个有臂间接触，分类可重叠。该采样覆盖整段关节行程，不代表实际任务中的碰撞概率。还找到一条起终点均无接触的关节线性插值，按每轴至多 1° 的间距采样，在进程 55.65% 处发现右臂 `link_3` 与 `link_5` 穿入。运行扩展测试生成的 `results.json` 会记录起终点关节角和接触体。

## 可达目标漏解与跳变

每臂 42 个测试目标由合法关节角经 MuJoCo 正运动学生成，包括 16 个内部样本、各轴两端及向内 0.25° 的构型，还有 home 和近奇异构型。每个目标分别从 home 和接近参考构型的初值求解，回代验收阈值为 0.4 mm 和 0.004 rad。

- **可达目标漏解。** 84 个目标中，58 个在两种初值下均解出，26 个在两种初值下均无解，即 168 次调用中有 52 次漏解。漏解的 26 个目标中，20 个具备无穿入的已知参考构型。32 个内部采样目标全通过。每臂漏解的 13 个目标分别位于 J1、J6 的两端及向内 0.25°，以及 J2 两端、J3 上限和 J4 两端。样本有意集中在限位附近，这一比例不能外推为一般工作空间的漏解率。
- **限位收缩对照。** cuRobo 的 LM 初值求解把候选关节活动区间的每端向内收缩全行程的 0.1%，J1 和 J6 分别约 0.328° 和 0.340°。在独立左臂试验中，仅把该内部搜索区间改到模型边界，84 次调用中的 26 次 `no_solution` 降为 0。75 个结果直接通过严格限位，另外 9 个结果有最多 8.75×10⁻⁸ rad 的数值越界，裁回精确边界后也全部通过独立 FK。主控制器仍使用 cuRobo 默认搜索余量。[cuRobo 对初值区间的处理](https://github.com/NVlabs/curobo/blob/v0.9.0/curobo/_src/solver/seed_ik/seed_ik_solver.py#L96-L101)
- **相邻 IK 指令。** 每臂四条连续轨迹，共 192 次目标更新，均求得解。超过 10° 的相邻关节变化为 0 次，但有 16 步既超过 2°，又超过已知连续参考解步长的 5 倍。最明显处，TCP 仅移动 0.214 mm、旋转 0.055°，参考关节最大变化 0.039°，右 J4 的 IK 指令变化达 4.697°。该步的参考构型和返回构型均无碰撞。以上阈值用于本次测试。
- **实际关节速度。** 在动力学测试中，每 2 ms 的位置指令增量都满足配置的斜率限制。快速返回时右 J1 的实测速度达到 378.3°/s，高于整臂指标 320°/s。相邻 IK 指令变化、执行器实际收到的指令增量和物理关节速度是三个不同的测量量。

## 复现

在包含 `ik` 脚本的目录下运行。主测试发现漏解、碰撞或超限时，写出完整数据并返回退出码 1。NPZ 按用例保存时间戳、14 路关节输出力矩、控制指令及该物理步结束时的关节角，列名记录在 `joint_order`。

```bash
./ik verify
./ik audit --trace audit_results/motor_traces.npz > audit_results/results.json
.venv/bin/python probe_ik_limits.py > audit_results/ik_limit_probe.json
```
